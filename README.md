# Bálint Lilla — Portfolio

Modern personal portfolio for **Bálint Lilla**, Senior Full Stack AI Engineer.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Motion for React
- Lucide icons

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Resume-backed content lives in `src/data/`:

- `profile.ts` — identity, summary, contact
- `experience.ts` — work history
- `skills.ts` — technical skills
- `projects.ts` — selected work case studies

Update GitHub URL in `profile.ts` when available (redacted in the source resume).

## Build

```bash
npm run build
npm start
```
